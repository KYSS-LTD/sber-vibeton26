# Отчёт об использовании ИИ

## В разработке

| Инструмент | Для чего | Что проверялось человеком и тестами |
|---|---|---|
| Codex (OpenAI) | Основная генерация кода backend, frontend, инфраструктуры и документации (так отмечено в [architecture.md](architecture.md)) | Автоматические тесты backend и Playwright, ручные испытания по [acceptance.md](acceptance.md), развёртывание на сервере ([testing.md](testing.md)) |
| Claude Code (Anthropic) | 10 октября 2026: аудит репозитория по критериям допуска и оценки, поиск расхождений между документами и кодом, подготовка документации | Запуск тестов, typecheck и сборки frontend, чтение кода; результаты зафиксированы в [testing.md](testing.md) |

Правило команды: код, написанный ИИ, считается нашим. Каждый участник должен уметь объяснить свой участок ([code-map.md](code-map.md)); факт генерации не заменяет проверку.

## В работающей системе

| Модель | Где работает | Что делает | Чего не делает |
|---|---|---|---|
| YOLOv8-face, YuNet | backend, CPU или GPU | Находят лицо в кадре | Не определяют личность |
| SFace | backend, CPU | Сравнивает лицо с тремя эталонами | Не принимает решение о проходе |
| MiniFASNet | backend, CPU или GPU | Оценивает живость (PAD) | Не гарантирует защиту от любой подмены |
| Qwen3 0.6B (Ollama) | локальный контейнер | Выбирает инструменты и номера фактов для помощника | Не пишет SQL, не пишет числа |
| GigaChat | внешний API, по ключу | То же, что Qwen3, если выбран администратором | То же |

Решение о проходе принимает код сервера по записанным проверкам ([passages.py](../backend/app/passages.py)), а не модель.

## Данные и ИИ

- Фотографии и шаблоны лиц обрабатываются локально, во внешние сервисы не отправляются.
- Внешнему провайдеру (GigaChat) уходят вопрос руководителя и факты помощника: имена сотрудников, смены, часы, отказы. Перед выбором GigaChat на реальных данных проверить требования к персональным данным.
- Каждый запрос к модели сохраняется в `llm_requests`: кто спросил, провайдер, выбранные инструменты, факты, ответ или код ошибки. Ключи и пароли туда не попадают.

## Известные проблемы качества ИИ

- Qwen3 0.6B — самая маленькая из моделей семейства; при неоднозначном вопросе она может выбрать не тот инструмент. Ответ при этом остаётся правдивым (факты из БД), но может не соответствовать вопросу.
- Реальный вызов GigaChat не выполнялся: ключ не был предоставлен. Контракт OAuth и чата проверен тестами с имитацией HTTP ([testing.md](testing.md)).
