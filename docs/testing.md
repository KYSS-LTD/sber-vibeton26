# Фактические результаты проверки — 10 октября 2026

Docker Engine на устройстве отсутствует. Установка Docker Desktop через winget завершилась после запроса UAC с кодом `4294967291`; установка WSL — с `0x80073d28` (нужны права администратора). Полный `docker compose up --build` и проверки внутри контейнеров **не выполнялись**.

Для проверки реализации запущены настоящие локальные сервисы: PostgreSQL 17.6 / PostGIS 3.6.2, SeaweedFS 4.48, Keycloak 26.4.7 и Ollama 0.12.3. API работает в отдельном Python 3.12.14 окружении, сайт — через Next.js; тесты браузера используют Chrome. Эти проверки не заменяют проверку Linux-образов и томов Compose.

|---|---|
| Backend: JWT, подписи устройства, ограничения API, PostgreSQL RLS/смены/эталоны/QR, heatmap, S3, gateway, модели и секреты | 25 passed |
| Гонка закрытия смены с геозапросом, два реальных подключения PostgreSQL | Запрос ждал блокировку, затем получил 409; точка не записана. Использована отдельная временная БД |

| GigaChat | OAuth и chat contract проверены HTTP-моками. Реальный внешний вызов и демонстрация второго провайдера не выполнены: ключ не предоставлен |
| pg_dump / pg_restore | Восстановлено в отдельную БД; сверены объекты, storage scopes и версия схемы |

Зависимости runtime и экспорта фиксируются отдельно. Образы Compose закреплены по digest; Qwen — по digest manifest. В репозиторий не входят локальные пароли, тестовые базы, фотографии, скачанные модели и инструменты.

Не выполнены ручные испытания сотрудников с камерой/телефоном, физической распечатки перед камерой, фонового GPS/доверия HTTPS на телефоне; не измерены FAR/FRR. Не проверены перезапуск Linux-контейнеров и восстановление полного комплекта Docker-томов. Полная матрица оставшихся испытаний — [acceptance.md](acceptance.md).

Неподвижный цифровой снимок в проверке получил высокий PAD score, но был отклонён случайными действиями. Это подтверждает необходимость совместной проверки и ограничения доверия к видеопотоку браузера; одна MiniFASNet не даёт абсолютной гарантии.
